👨‍💻 Presentación

Estudiante de Ingeniería de Sistemas y Computación en la Universidad Peruana Los Andes. Este portafolio recopila los trabajos académicos del curso Base de Datos II, demostrando dominio progresivo de conceptos como SQL, normalización, procedimientos almacenados y tecnologías NoSQL.

📚 Competencias del Curso

A lo largo de las 16 semanas se desarrollan competencias en diseño de bases de datos relacionales, escritura de consultas SQL complejas, implementación de objetos de base de datos y comprensión de sistemas NoSQL modernos como herramientas complementarias al modelo relacional.
